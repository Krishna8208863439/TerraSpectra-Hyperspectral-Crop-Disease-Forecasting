# Feature Comparison Matrix: Smart Kisan AI vs. TerraSpectra

| Category / Domain | Smart Kisan AI (Legacy Platform) | TerraSpectra (Hyperspectral Intelligence Platform) | Rationale & Transformation Strategy |
| :--- | :--- | :--- | :--- |
| **Primary Domain** | General-purpose agricultural assistance | Specialized Hyperspectral Imaging, Spectral Signatures & Disease Forecasting | Re-architected for high-dimensional scientific spectral remote sensing & precision crop diagnostics. |
| **Input Data Modality** | Standard RGB smartphone photos (3 channels: R, G, B) | Hyperspectral Data Cubes ($\ge 50-250$ contiguous spectral bands, ENVI `.hdr`/`.raw`, multi-band GeoTIFF, `.npy`) | Distinguishes spectral reflectance across NIR, RedEdge, and SWIR wavelengths unavailable in standard 3-band RGB. |
| **Data Ingestion** | Standard JPEG/PNG image upload | Complete ENVI header parser, calibrated radiance/reflectance cubes, wavelength metadata extractor, dimension validation | Handles high-dimensional 3D hypercubes $(H \times W \times B)$ with automatic wavelength mapping $(400-1000\text{ nm})$. |
| **Spectral Analysis** | None (pixel RGB color only) | Spectral signature extraction, band-wise reflectance profiling, noise filtering (Savitzky-Golay), continuum removal, PCA dimensionality reduction | Computes plant biological spectral indices (NDVI, NDRE, PRI, PSRI, MCARI, WBI) directly from calibrated reflectance. |
| **Disease Detection** | MobileNetV2 RGB image classification | Ensemble Hyperspectral 1D/3D CNN, Random Forest & SVM trained on spectral reflectance curves | Detects physiological & cellular chlorophyll degradation before visible symptoms appear on leaves. |
| **Early Crop Stress** | None (only classified visible symptoms) | Early stress anomaly detection (autoencoder spectral reconstruction error + normalized difference stress indicators) | Clearly demarcates early sub-visual physiological stress (water/nitrogen/drought) from confirmed fungal/bacterial infection. |
| **Crop Disease Forecasting** | None | Multi-modal longitudinal forecasting integrating spectral trajectory + environmental telemetry (temperature, humidity, rainfall, leaf wetness) | Prevents false claims of single-image future forecasting by coupling longitudinal spectral degradation with disease epidemiological models. |
| **Environmental Intelligence** | Basic localized weather card | Integrated Disease Risk Weather Index (Open-Meteo API, hourly temperature/humidity microclimate & pathogen sporulation risk index) | Dynamically feeds forecasting engine with cumulative degree days and continuous humidity risk windows. |
| **Explainable AI (XAI)** | None | SHAP feature attribution over spectral bands, wavelength importance ranking, spectral signature delta graphs | Explicitly demonstrates to agronomists and researchers *why* specific absorption troughs (e.g. 680 nm chlorophyll absorption, 705 nm red edge) drove prediction. |
| **Research Analytics** | Basic count of previous scans | Comprehensive research lab dashboard: confusion matrices, ROC-AUC curves, classification F1 metrics, experiment tracking & batch evaluation | Scientific agricultural intelligence interface for research institutions and agronomists. |
| **Community & Marketplace** | Buy/Sell marketplace, community forum, farmer cart | Removed | Stripped consumer commerce features to focus strictly on precision agricultural research & diagnostics. |
| **Chatbot** | General AgriExpert prompt | TerraSpectra Research Assistant (specialized spectral analysis, vegetation index guidance, disease epidemiology) | Tailored strictly to spectral diagnosis and agricultural remote sensing guidance. |
| **Architecture** | Dual Node.js + Flask backends | Unified high-performance Python FastAPI scientific backend + modern React 18 / Tailwind scientific dashboard | Eliminates redundant microservices, maximizes Python scientific ecosystem compatibility (NumPy, SciPy, PyTorch, Scikit-learn). |
